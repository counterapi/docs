# API Endpoints

!!! danger "V1 is deprecated"
    As of **August 7, 2026**, the v1 API has been retired and no longer serves requests. **V2 is now the only available API version.**

## [V2 Endpoints (Current)](endpoints/v2.md)

Our current and only supported API with:
- User authentication
- Private counters
- Higher rate limits (600 requests per minute)
- Additional security features

[View V2 Endpoints Documentation →](endpoints/v2.md)

## [V1 Endpoints (Deprecated)](endpoints/v1.md)

Our original API, **no longer available**:
- No authentication required
- Public counters only
- Limited rate (30 requests per minute)
- Retired as of August 7, 2026

[View V1 Endpoints Documentation (migration notes) →](endpoints/v1.md)

## Choosing the Right Version

- **All projects** should use [V2 endpoints](endpoints/v2.md) — it is the only available version.

For more information about rate limits, see our [Rate Limits](rate-limit.md) documentation.
